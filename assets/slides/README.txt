========================================================================
ChallanX Rajasthan - Custom Traffic Challan Slide Images Directory
========================================================================

Place your custom image assets into this folder (f:\ChallanX website\assets\slides\):

Recommended image filenames:
- slide1.jpg (or slide1.png / slide1.webp) : Highway CCTV Speed Radar Notice
- slide2.jpg (or slide2.png / slide2.webp) : Parivahan e-Challan Virtual Court Screen
- slide3.jpg (or slide3.png / slide3.webp) : Traffic Police Handheld Verification
- slide4.jpg (or slide4.png / slide4.webp) : Lok Adalat Receipt & Judicial Settlement

The website image slider in the hero section automatically checks for local images in this folder and smoothly transitions between them with fallback support!
